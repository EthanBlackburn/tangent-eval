# Datasets

Third-party material for writing cases: 38 copies of public datasets, fixtures and detection content on AI-agent abuse of macOS endpoints and on agent security in general, each pinned to the commit or revision it was taken at. Nothing in the evals needs them to run; they are the raw material behind cases, and the archive a result can cite.

Each directory here holds a `SOURCE.txt` (URL, commit or revision, license). The copies themselves, 470 MB, come from this repository's release asset:

```bash
python3 -I datasets/fetch.py        # downloads the archive, checks its SHA-256, extracts into datasets/
```

Every copy is verbatim, what its upstream published at the pinned revision, with the upstream LICENSE beside it where there was one, and stays under that license: the ones with conditions are Elastic License 2.0 (the Elastic rules, artifacts and integration samples), GPL-3.0 (`sbousseaden-macos-attack-dataset`), the Detection Rule License 1.1 (`sigma-macos-rules`) and CC-BY-SA-4.0 (`basharena-kernel-evidence`, whose card carries a canary GUID so the data stays out of training sets; keep it so). `sources.json` is the catalog of the 84 sources that may be redistributed (the copies, and pages worth reading that were not copied), each with what it holds, how it could be used, which techniques of the [Endpoint AI Agent Abuse catalog](https://github.com/0x4D31/endpoint-ai-agent-abuse) it bears on, and what `eslogger` would see of it; `eaa-catalog.json` is that catalog at v0.5.1 (CC0). Sources whose license does not allow redistribution, or that hold real people's sessions, are not here.
